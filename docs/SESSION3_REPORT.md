## What changed
- Pages are loaded on demand (React lazy + Suspense). Plotly loads only when a chart comes within 300 px of the screen.
- Dataset files are requested with their content version (`?v=`), so browsers cache them until the data changes. Manifest and status files are always revalidated.
- Fonts are self-hosted from npm (`@fontsource`, Latin subsets): no third-party font requests.
- Bundle report: `ANALYZE=1 npm run build` writes `website/bundle-report.html`.
- Charts: visible PNG and SVG download buttons (keyboard reachable, named by figure ID), data table and text reading on every Cost Cap chart as well as Moneyball. Plotly's hover toolbar removed (not keyboard or crawler friendly).
- URLs: path-based routes (`/research/does-money-buy-speed/`) instead of `#/`. The build writes a static HTML file per page with its own title, description, canonical URL, Open Graph and Twitter tags, and Article or WebSite JSON-LD; plus `404.html` fallback, `robots.txt` and `sitemap.xml`. Page bodies are still rendered in the browser.
- Social preview images (1200x630, text only) in `website/public/og/`, generated by `website/scripts/og_images.py`.
- Citation: `CITATION.cff` (no DOI listed; none exists). Each article has a "How to cite" block (APA-style and BibTeX) that states it is a research design, not peer reviewed, with the text revision date. No publication date is invented.
- Changelog: `data/manual/changelog.yaml` (hand-written) plus automatic dataset entries written by the pipeline only when a dataset's content version changes. Published as `changelog.json` and shown at `/changelog`. Categories keep data, methodology, analysis, publications and website changes apart.
- Reproducibility: the manifest records the Python and package versions of each build; shown on Methodology.
