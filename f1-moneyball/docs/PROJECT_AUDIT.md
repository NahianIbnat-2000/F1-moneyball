# F1 Moneyball: project audit

Audit date: 20 November 2026. Scope: the repository at commit `83dbce0`, the published datasets in
`website/public/data`, the website, the working paper and the CI workflows. Every finding below was
checked against the code or data; where a figure is quoted, the command that produced it is in the
"Evidence" column or in section 4.

Priority levels: **Critical** (a published result or claim is wrong or unsupported), **High** (a result
could change, or a reader could be misled), **Medium** (weakens reproducibility, usability or
credibility), **Low** (polish).

## 1. Architecture and technology

| Layer | What exists |

## 2. Existing research capabilities (verified)

- **Study 01, money and results:** 8 team lineages, 104 team-seasons (2010–2025), 95 in the lagged models. Pooled, team FE and TWFE on lagged log turnover, staff costs and headcount; clustered SEs plus restricted wild cluster bootstrap (Webb weights, 9,999 draws, seed `20261119`); leave-one-team-out; no-reset-seasons; championship position outcome; H3 cost-cap interaction; H4 operations controls.
- **Study 02, cost cap:** competitive balance indices, interrupted time series with placebo break years, dose-response design.
- **Study 03, Grand Prix tourism:** Austria (9 states, 2008–2025) and Singapore (2005–2025); event study with HAC errors; synthetic control for Styria with in-country donors and placebo-in-space; analysis ends 2019-12.

## 3. Verified strengths

1. **Provenance is already detailed.** 525 of 527 financial rows carry a source URL, document title, PDF page, transformation note, confidence level, entry method and (where relevant) a comparability warning. The two remaining rows are explicit `missing` rows (Silverstone 2017–2018), not gaps.
2. **Few-cluster inference is handled correctly in principle:** restricted wild cluster bootstrap with Webb weights, documented seed and draw count.
3. **Results cannot silently drift from text:** the paper's claim checks, the website's `resultsBasedOn` version stamps, and the content-hash versioning.
4. **Causal language is consistently avoided** in the paper, articles, FAQ and summary page.

## 4. Findings

### Critical

| # | Finding | Evidence | Action |
|---|---|---|---|
| C1 | **The headline within-team points-share result is not robust to changes in accounting scope.** Mercedes (from 2022), McLaren (2021–2024), Williams (from 2020) and Red Bull (from 2014) report group-consolidated accounts in some years and company-only accounts in others. With a control for the scope of the lagged-year accounts, the staff-cost TWFE coefficient barely moves (0.186 → 0.184), but its bootstrap p-value rises from 0.04 to about 0.10. The championship-position result survives (staff costs: bootstrap p 0.015 → 0.022). The abstract currently leads with "points share ... bootstrap p = 0.04". | Re-estimation with a control for the lagged year's account scope; now the `scope_control` check in `robustness.py` | Add the scope check to the robustness table (done in Phase 2). **Rewording the abstract changes the paper's emphasis, so it needs the author's approval** (proposed text in §6). |

### High

| # | Finding | Evidence | Action |
|---|---|---|---|
| H1 | **Accounting periods of unequal length are not annualised.** Leafield 2010 (457 days), Silverstone 2019 (395 days), Banbury 2016 (547 days) and one Silverstone stub period (122 days, not mapped to a season). | `financial_year_end − financial_year_start` | Add an annualised sensitivity check and a validation warning. Measured impact is small (staff-cost TWFE 0.186 → 0.182), so originals stay the main specification. |
| H2 | **No correction for multiple testing.** Six within-team tests are reported for the main specification (3 measures × 2 outcomes). With a Holm adjustment of the bootstrap p-values, none is below 0.05; the strongest (staff costs → position) is 0.078. The paper mentions the six tests in words only. | Holm on published `p_wild` | Publish Holm-adjusted p-values as part of the robustness output and mention them in the paper. |
| H3 | **No real-terms (inflation-adjusted) money measures.** Season fixed effects absorb common inflation in FE models, but the pooled model and all descriptive figures are nominal. | Code search: no deflator anywhere | Add a deflator path using the ONS CPI index. **Blocked:** ons.gov.uk is not reachable from the build environment; needs one CSV downloaded by the author (instructions in `docs/REAL_TERMS.md`). |
| H4 | **Validation does not flag comparability risks** that matter for the models: non-12-month periods, changes in accounting scope within a team, or large year-on-year jumps. | `validation/checks.py` | Add these as warnings (not errors: they are real features of the filings). |

### Medium

| # | Finding | Action |
|---|---|---|
| M1 | Dependencies are lower-bounded (`pandas>=2.2` etc.), not pinned. Results could change with a library release. | Add `requirements-lock.txt` with the exact versions the tests pass on. |
| M2 | `robustness.py` docstring says "only six teams"; the sample has eight. `docs/` holds four session reports that read as history, not documentation. | Fix the docstring; keep the session reports but point to this audit as current. |

| M5 | The interactive pages show the main estimates but no single place lets a reader compare specifications, inference methods and robustness checks side by side. | Build the Econometrics Lab from the published `model_results` and `robustness_checks` (no new estimates, no live estimation). |
| M6 | Accessibility has not been tested with an automated tool. | Run axe-core in CI when a headless browser is available; until then, report as untested. |

## 5. Security and deployment

- No secrets in the repository; workflows use `GITHUB_TOKEN` with `contents: write` only where they commit.
- `website/index.html` was overwritten twice by manual uploads; `deploy.yml` now refuses to publish if it is not the React entry page.
- No server-side code runs on the public site; the Econometrics Lab will load precomputed results only (no user-supplied code).

## 6. Proposed wording change (needs author approval)

Current abstract sentence: "...clearest for staff costs: 10% more staff spending goes with a points share about 1.8 percentage points higher the next season (wild cluster bootstrap p = 0.04) and a better championship position (bootstrap p = 0.01)."

Proposed: "...clearest for staff costs and championship position: 10% more staff spending goes with a finish about 0.4 places higher the next season (wild cluster bootstrap p = 0.01). The matching points-share estimate is similar in size but less certain once changes in accounting scope are controlled for, and no within-team result survives a correction for multiple testing at the 5% level."

## 7. Implementation plan (priority order)

1. Robustness: scope control, annualised periods, Holm-adjusted p-values (C1, H1, H2). Tests.
2. Validation warnings for period length, scope changes, year-on-year jumps (H4). Tests.
3. Real-terms path with documented ONS source; skipped with a clear message until the file exists (H3).
4. Pinned dependency lock file; docstring fixes (M1, M2).
5. Econometrics Lab page from published outputs (M5).
6. Citation metadata (M3).
7. Paper: report the new checks in Table 3 and the text; abstract change only after approval (C1).
8. Verification report.

Dependencies: step 7 needs the pipeline to publish the new robustness rows first (the paper is built from published data). Step 3 needs the CPI file.
